# Tic-Tac-Toe-Game-in-C
I have tried to create a fun Tic-Tac-Toe game in C using very basic operations and flow control statements. In this code, I have eliminated most of the problems that could occur while attempting to play like entering something out of range and the input type being unrecognised (char in this case).
Just copy the code and run it in your IDE.
